# REPAIR implementation plan

**Goal:** Run the paper's alignment/interpolation/repair pipeline and document its SDK.

**Architecture:** Small PyTorch package, architecture-specific matching, reusable
normalization core, CLI experiment runner. Source pinned in `upstream/`.

**Tech stack:** Python >=3.10, PyTorch, NumPy, SciPy; optional torchvision.

**Spec:** [Design](../specs/2026-09-15-repair-design.md).

User's MVP instructions take precedence over review cycles and extra approvals.
All work stays inside `repair/`; no commits or machine configuration changes.
